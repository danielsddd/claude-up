# Contributing

claude-up is a one-person project, so pull requests aren't accepted for now. Issues are very welcome:

- **A bug:** open an issue with your Claude Code version, the app (desktop, mobile or terminal), what you did and what you saw.
- **An idea for a new mod:** open an issue describing it.

You're free to fork any mod and change it for your own Claude Code; the [MIT license](LICENSE) allows it.
